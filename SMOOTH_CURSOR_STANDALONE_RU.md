# SmoothCursor внутри Termux APK

Эта версия встраивает SmoothCursor непосредственно в `terminal-view` и приложение Termux. Для эффектов не нужны root, LSPosed, Xposed или отдельный APK модуля.

Настройки открываются через контекстное меню терминала → **Настройки SmoothCursor**. В APK перенесены плавный курсор, его цвет/обводка/шлейф, плавная прокрутка и скорость, отступы, свечение и плавное появление текста.

Настройки и функции, связанные с изображениями, фоном, заставкой и графическими протоколами iTerm2/kitty, намеренно не перенесены.

Для сборки нужны JDK 17 и Android SDK:

```bash
./gradlew :app:assembleDebug
```

Gradle настроен выпускать универсальный APK и APK для ABI. Файлы сборки находятся в `app/build/outputs/apk/debug/`.
